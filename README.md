# 今日の習慣 Webアプリ — 案C：別パネル

GitHub PagesなどのHTTPS対応の静的ホスティングに公開し、iPhoneのSafariからホーム画面に追加して使うWebアプリ版です。Apple Developer Programへの登録は不要です。

## 主な機能

- 習慣の追加、名前・絵文字アイコン・メモの変更、削除
- 42種類の絵文字からの選択と、絵文字キーボードからの自由入力
- 初期習慣は「歯磨き」「シャワー」の2つ
- 習慣カード右端のつまみをスライドして並び替え
- 習慣ごとの1日の目標回数設定と、達成までの回数カウント
- 同じ高さの習慣行に横棒グラフを常時表示。進捗バーをタップすると円グラフの達成率を表示。複数回目標はバー両端の「−」「＋」ボタンまたは回数表示から記録
- 習慣カードからポモドーロタイマーを開始（15分・25分・45分から選択、休憩は5分）
- タイマーに集中経過を示す円形グラフを表示。経過に合わせて連続的に進みます
- 集中時間の完了で選択中の習慣を1回分記録し、完了セッション・集中時間を統計に保存
- 今週の集中時間・セッション数、習慣ごとの累計集中時間を表示
- 習慣ごとの実施曜日設定。設定変更はその日以降に反映し、過去の予定と統計を維持
- 曜日指定、または週あたりの目標回数を設定。週目標はその週の好きな日に記録でき、週ごとの連続達成数も表示
- 設定した曜日での連続達成日数を習慣リストと統計に表示（予定のない曜日は連続判定から除外）
- 達成操作をチェックボックス、スイッチ、達成ボタンから選択
- 過去7日、30日、全期間の振り返り
- 日付ごとの達成項目表示と、過去記録の修正
- 統計に今週・今月・全期間の達成率と、期間内の日ごとの推移を表示
- 曜日別の平均達成率と曜日ごとの習慣別達成率
- 今日の円形達成率、目標回数の進捗バー、統計画面の習慣別達成率バー
- 統計に全期間の達成率を示すドーナツグラフと達成数・未達成数を表示
- 円形・棒グラフの値が変わるときは短く滑らかに伸縮
- 全期間の記録日数、チェック数、達成率
- バックアップJSONの書き出し・読み込み（読み込み時は現在の端末のデータを置き換え）
- 使い心地メモを端末内に保存
- 10種類の配色テーマ（オレンジ×ブラックを含む）と背景色・文字色の調整
- 達成時にチェックや進捗が短くスライドインする控えめなアニメーション（視差効果を減らす設定では停止）
- ブラウザー内への記録保存、初回表示後のオフラインキャッシュ

## GitHub Pagesで公開

1. GitHubにサインインし、**New repository** から新しいリポジトリを作成します。GitHub Freeの場合はPublicを選びます。
2. このフォルダー内の `index.html`、`manifest.webmanifest`、`service-worker.js`、`icon-180.png`、`icon-192.png`、`icon-512.png` をリポジトリの一番上にアップロードしてCommitします。
3. リポジトリの **Settings → Pages** を開き、**Deploy from a branch**、Branchを `main`、Folderを `/ (root)` にして保存します。
4. 公開された `https://<GitHubのユーザー名>.github.io/<リポジトリ名>/` をiPhoneのSafariで開きます。
5. Safariの共有メニューから **ホーム画面に追加** を選び、「ウェブアプリとして開く」をオンにして追加します。

習慣とチェック記録はiPhone内のブラウザー保存領域に保存し、アカウントやサーバーには送信しません。公開リポジトリに含めるのはアプリのコードだけです。GitHub Pagesのサイト自体は誰でも閲覧できるため、個人情報をファイルに書かないでください。

## バックアップと機種変更

設定画面の「バックアップを書き出す」でJSONファイルを保存してください。習慣、日々の記録、集中セッションもバックアップに含みます。機種変更後は同じ公開URLをホーム画面に追加し、「バックアップを読み込む」からそのファイルを選びます。読み込み時にその端末にあるデータは置き換わるため、必要なら先に書き出してください。アプリのデータは端末間では自動同期されません。

ポモドーロはアプリを閉じている間に通知音が鳴らない場合があります。アプリに戻ると、保存した終了時刻から残り時間を更新します。

## iPhoneで数日使って見直す

数日間、普段どおり記録して、押しづらい操作・迷った画面・続けにくい設定を設定画面の「使い心地メモ」に残してください。メモは端末内に保存されます。変更案を共有するときは、個人情報を書かず、アプリのどの画面で困ったかを伝えると改善しやすくなります。

## 公開後の更新

更新版のファイルをリポジトリの同じ場所にアップロードし、既存ファイルを置き換えてCommitします。GitHub Pagesの更新完了後、ホーム画面のWebアプリを一度閉じて開き直してください。チェック記録や追加した習慣は、同じURLであれば端末内に残ります。以前のチェック記録は「1回達成」として引き継がれます。
